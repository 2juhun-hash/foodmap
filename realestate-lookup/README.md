# 부동산 공공데이터 조회 (realestate-lookup)

국토교통부 **실거래가**와 **건축물대장**을 명령 한 줄로 조회해 CSV(엑셀용)로 저장합니다.
[PublicDataReader](https://github.com/WooilJeong/PublicDataReader) 라이브러리를 사용합니다.

## 1. 준비 (최초 1회, 약 20분 + 승인 대기)

1. Python 3.9 이상 설치
2. 패키지 설치
   ```bash
   cd realestate-lookup
   pip install -r requirements.txt
   ```
3. [공공데이터포털](https://www.data.go.kr) 회원가입 후 아래 API를 각각 **활용신청** (자동승인)
   - 국토교통부_상업업무용 부동산 매매 실거래가 자료
   - (필요 시) 국토교통부_토지 매매 실거래가 자료 / 오피스텔 매매·전월세 / 연립다세대 등
   - 국토교통부_건축HUB_건축물대장정보 서비스
   > 승인 직후에는 키가 바로 동작하지 않을 수 있습니다. 보통 1~2시간 안에 활성화됩니다(경험상 추정이며, 확인되지 않음).
4. 마이페이지의 **일반 인증키(Decoding)** 를 복사해 `.env` 파일을 만듭니다.
   ```bash
   cp .env.example .env   # 그다음 .env 안의 값을 실제 키로 교체
   ```
   `.env`는 Git에 올라가지 않도록 설정되어 있습니다.

## 2. 사용법

### 실거래가
```bash
# 마포구 상업업무용(꼬마빌딩·근생) 최근 12개월
python lookup.py trade --region "서울 마포구" --type 상업업무용 --months 12

# 서교동만
python lookup.py trade --region "서울 마포구" --type 상업업무용 --dong 서교동

# 토지 24개월 / 오피스텔 전월세
python lookup.py trade --region "성남시 분당구" --type 토지 --months 24
python lookup.py trade --region "서울 강서구" --type 오피스텔 --trade 전월세
```
- 유형: `상업업무용`(기본) `토지` `오피스텔` `아파트` `연립다세대` `단독다가구` `공장창고등` `분양입주권`
- 결과: `output/실거래_….xlsx` 한 파일에 시트 3개
  - **요약**: 건물유형(일반/집합) → 건물주용도별 건수·거래금액·평단가 중앙값/최소/최대. 일반건물(꼬마빌딩) 시세는 `일반 / 소계` 행을 보세요.
  - **조건**: 조회 조건, 요약 제외 건수와 사유, 계산식, 주의사항
  - **거래**: 전체 거래 원본. `요약제외사유` 열로 무엇이 왜 빠졌는지 확인
- 요약에서 빼는 거래: **해제거래, 지분거래, 직거래**(직거래도 넣으려면 `--include-direct`)
- 평단가 = 거래금액(만원) ÷ (면적㎡ ÷ 3.305785). 건물면적 기준과 대지면적 기준을 모두 계산합니다.

### 건축물대장
```bash
python lookup.py ledger --address "서울 마포구 서교동 395-166"
python lookup.py ledger --address "경기 양평군 양서면 목왕리 산12-3"
```
- 주소는 **법정동 + 지번** 형식이어야 합니다. 도로명이나 행정동 주소는 인식하지 못합니다.
- 출력 항목: 주용도, 구조, 층수, 대지면적·연면적, 건폐율·용적률, 주차, 허가일·착공일·사용승인일, 지역·지구·구역

## 3. 해석할 때 주의할 점

| 항목 | 주의할 점 |
|---|---|
| 지번 표시 | 집합건물 거래는 지번이 그대로 나오지만, 일반건물·토지 거래는 `3**`처럼 가려지는 경우가 있습니다(실행 결과 기준 관찰, 공식 기준은 확인되지 않음). 가려진 거래는 법정동·면적·건축년도로 유사성을 판단하세요. |
| 직거래 | 같은 날 같은 지번에서 법인→개인 `직거래`가 여러 건이면 분양·특수관계 거래일 수 있어 시세 비교에서 따로 보세요. |
| 집합건물 | 상업업무용 중 `건물유형=집합`은 호실 단위 거래입니다. 대지면적당 평단가는 대지지분 기준이라 일반건물과 직접 비교하면 왜곡됩니다. |
| 신고 시차 | 계약 후 30일 안에 신고하므로 최근 1~2개월 데이터는 덜 채워져 있습니다. |
| 지분거래 | `지분거래구분`이 표시된 거래는 평단가를 왜곡하므로 따로 보세요. |
| 위반건축물 | 이 API에는 위반건축물 표시가 없습니다. 정부24·세움터에서 대장 원본으로 확인하세요. |
| 소유자 정보 | 건축물대장 소유자 API는 별도 승인이 필요하며 개인정보라 이 스크립트에서 조회하지 않습니다. |
